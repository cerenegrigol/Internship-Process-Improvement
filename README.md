# Internship Process Improvement

## Business Problem

During my internship, I observed that approved interns were not always contacted on time, and document tracking relied heavily on manual file reviews.

This created unnecessary operational risks and reduced process visibility.

## Root Cause

- No centralized tracking system
- Manual document checks
- Limited visibility into internship status

## Solution

Designed an Excel-based internship tracking system that monitors:

- Contact status
- Document status
- Internship dates
- Department
- Current process status

## Outcome

- Improved process visibility
- Reduced manual searching
- Supported a more organized internship onboarding process
